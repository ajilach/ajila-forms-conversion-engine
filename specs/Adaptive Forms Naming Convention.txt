Guidelines for Adaptive Forms Label Definition
    • All labels in Adaptive Forms will start with the <PREFIX> of the Component Type
    • The recommended label naming convention in an adaptive form is the <UpperCamelCase>
      style, which capitalizes the first letters of all words in a compound word, including the first word.
    • The underscore "_" will be used when additional attribute clustering is
      required. (e.g: TXT_FirstName_ClientAdvisor)

Adaptive Form - File Naming Convention:
Adaptive form file names will include the prefix <AF> and the <4 chars FormBaseCode>, as a single HTML file
will be shared across multiple mandators & languages.
<prefix AF>_<FormBaseCode> (e.g: AF_AAAA, AF_AAAZ)

Adaptive Form - Folder Naming Convention and Structure
An Adaptive Forms folder name will contain the prefix <AF> and the <first 2 chars from the FormBaseCode>,
representing the range of forms to be included in each folder.
<AF>_<First 2 chars from the FormBaseCode>
Example: folder AF_AA will include all adaptive forms with the formbasecode starting with AF_AA..:

Adaptive Form Set - File Naming Convention
Adaptive Form Set file names will include the prefix <AFS> and <4 digits AdaptiveFormSetBaseCode>
<prefix AFS>_<4 digits AdaptiveFormSetBaseCode> (e.g: AFS_0000, AFS_0001)
